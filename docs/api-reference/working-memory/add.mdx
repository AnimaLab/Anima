## POST /api/v1/working-memory

Adds a provisional entry to working memory with status `pending`. A later [commit](/api-reference/working-memory/commit) turns pending entries that score high enough into long-term memories; entries left pending past `expires_at` become `expired`.

<ParamField header="X-Anima-Namespace" type="string" required>
  Target namespace
</ParamField>

## Request Body

<ParamField body="content" type="string" required>
  Entry text, stored trimmed. Blank content gives `400`.
</ParamField>

<ParamField body="metadata" type="object">
  Arbitrary metadata, carried into the long-term memory on commit
</ParamField>

<ParamField body="conversation_id" type="string">
  Conversation the entry belongs to. On commit it becomes the memory's `episode_id`.
</ParamField>

<ParamField body="provisional_score" type="number" default="0.5">
  Initial estimate of how worth keeping the entry is, clamped to 0.0-1.0
</ParamField>

<ParamField body="ttl_seconds" type="integer" default="7200">
  Time to live in seconds, clamped to 30-604800 (7 days); sets `expires_at`
</ParamField>

## Response

<ResponseField name="entry" type="object">
  The created entry: `id`, `namespace`, `content`, `metadata`, `provisional_score`, `status` (`pending`), `conversation_id`, `expires_at`, `committed_memory_id` (`null`), `created_at`, `updated_at`. See [List Working Memory](/api-reference/working-memory/list) for the fields.
</ResponseField>

## Example

```bash
curl -X POST http://localhost:3000/api/v1/working-memory \
  -H "Content-Type: application/json" \
  -H "X-Anima-Namespace: default" \
  -d '{
    "content": "I prefer window seats on long flights.",
    "conversation_id": "conv-42",
    "provisional_score": 0.6,
    "ttl_seconds": 7200
  }'
```
