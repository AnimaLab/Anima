## Base URL

```
http://localhost:3000
```

All API endpoints are prefixed with `/api/v1/` except for the health checks at `/health` and `/health/ready`.

## Authentication

When the server has an API key (`ANIMA_API_KEY` or `[server] api_key`), every `/api/v1/` request must send `Authorization: Bearer <key>`; requests without it get `401`. A key is mandatory when the server binds a non-loopback address. Without a key, the API only answers requests addressed to a loopback host.

Data is isolated by namespace. Include the `X-Anima-Namespace` header on all `/api/v1/` requests:

```
X-Anima-Namespace: default
```

## Error Format

Errors are returned as JSON with an `error` field:

```json
{
  "error": "Memory not found"
}
```

HTTP status codes follow standard conventions: `400` for bad requests, `404` for not found, `500` for internal errors.

## Common Headers

| Header | Required | Description |
|--------|----------|-------------|
| `Content-Type` | Yes (for POST/PUT) | Always `application/json` |
| `X-Anima-Namespace` | Yes | Target namespace for the request |
