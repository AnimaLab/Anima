---
title: 'Create Memory'
description: 'Store a new memory'
---

## POST /api/v1/memories

<ParamField header="X-Anima-Namespace" type="string" required>
  Target namespace
</ParamField>

## Request Body

<ParamField body="content" type="string" required>
  Memory text content. Empty content gives `400`.
</ParamField>

<ParamField body="tags" type="string[]">
  Optional tags for categorization
</ParamField>

<ParamField body="consolidate" type="boolean" default="true">
  Whether to compare the new memory with similar ones and let the LLM consolidator decide to keep, merge or supersede. Requires an LLM backend. A newly created memory is queued for background reflection.
</ParamField>

<ParamField body="episode_id" type="string">
  Optional episode identifier to group related memories. Defaults to `metadata.session` when present.
</ParamField>

<ParamField body="category" type="string">
  Semantic category: `identity`, `preference`, `environment`, `routine`, `task`, `inferred`, `general`, or any custom category defined in config. Default: `"general"`
</ParamField>

<ParamField body="source" type="string">
  How this memory was created: `user_stated`, `agent_observed`, `inferred`, `promoted`. Default: `"user_stated"`. Controls default confidence.
</ParamField>

<ParamField body="metadata" type="object">
  Arbitrary key-value metadata to attach to the memory
</ParamField>

## Response

<ResponseField name="id" type="string">
  ID of the stored memory, or of the existing memory when the content was a duplicate
</ResponseField>

<ResponseField name="action" type="string">
  What happened:
  - `created`: a new memory was stored (also when consolidation superseded an older one)
  - `deduplicated`: a memory with the same content already exists in the namespace; `id` is that memory
  - `no_change`: the consolidator found the content already captured; `id` is the closest existing memory
  - `updated`: the consolidator merged the content into an existing memory; `id` and `merged_into` are that memory
</ResponseField>

<ResponseField name="merged_into" type="string | null">
  ID of the existing memory the content was merged into, set when `action` is `updated`
</ResponseField>

## Example

```bash
curl -X POST http://localhost:3000/api/v1/memories \
  -H "Content-Type: application/json" \
  -H "X-Anima-Namespace: default" \
  -d '{
    "content": "I love hiking on weekends.",
    "tags": ["preference", "outdoors"],
    "consolidate": true
  }'
```

```json
{
  "id": "01J9Z3K4M5N6P7Q8R9S0T1V2W3",
  "action": "created",
  "merged_into": null
}
```
