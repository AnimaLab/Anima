---
title: 'Update Memory'
description: 'Update an existing memory'
---

## PUT /api/v1/memories/\{id\}

<ParamField header="X-Anima-Namespace" type="string" required>
  Target namespace. A memory outside it (or its children) gives `403`.
</ParamField>

<ParamField path="id" type="string" required>
  Memory ID
</ParamField>

## Request Body

At least one of `content`, `importance` or `tags` is required; an empty body gives `400`.

<ParamField body="content" type="string">
  Updated memory text. The memory is re-embedded.
</ParamField>

<ParamField body="importance" type="integer">
  Updated importance score
</ParamField>

<ParamField body="tags" type="string[]">
  Updated tags (replace the current ones)
</ParamField>

## Response

<ResponseField name="id" type="string">
  Memory ID
</ResponseField>

<ResponseField name="updated" type="boolean">
  Always `true` on success
</ResponseField>

Each change records a revision (operation `update_content` or `update_metadata`) in the memory's [revision history](/api-reference/revisions/list). To also change `metadata` or `memory_type`, record an actor and reason, and get the new revision number back, use `POST /api/v1/memories/{id}/patch`.

```json
{
  "id": "01J9Z3K4M5N6P7Q8R9S0T1V2W3",
  "updated": true
}
```
