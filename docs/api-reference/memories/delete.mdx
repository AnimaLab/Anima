---
title: 'Delete Memory'
description: 'Delete a memory by ID'
---

## DELETE /api/v1/memories/\{id\}

<ParamField header="X-Anima-Namespace" type="string" required>
  Target namespace. A memory outside it (or its children) gives `403`.
</ParamField>

<ParamField path="id" type="string" required>
  Memory ID
</ParamField>

## Response

The delete is permanent: a final `hard_delete` revision snapshots the memory and records an audit event, then the memory is removed from the store and its vector, keyword and sparse indexes.

```json
{
  "id": "01J9Z3K4M5N6P7Q8R9S0T1V2W3",
  "deleted": true
}
```
