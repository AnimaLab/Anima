---
title: 'Create Batch'
description: 'Store multiple memories in a single request'
---

## POST /api/v1/memories/batch

<ParamField header="X-Anima-Namespace" type="string" required>
  Target namespace
</ParamField>

## Request Body

<ParamField body="items" type="object[]" required>
  Array of 1 to 2000 memory objects, each with `content` (required, non-empty), `tags`, `episode_id` and `metadata`. `episode_id` defaults to `metadata.session` when present. Items are stored as `raw` memories, without deduplication or consolidation.
</ParamField>

<ParamField body="reflect" type="boolean" default="true">
  Whether to queue the inserted memories for background reflection
</ParamField>

## Response

<ResponseField name="created" type="integer">
  Number of memories stored
</ResponseField>

<ResponseField name="ids" type="string[]">
  IDs of the stored memories, in request order
</ResponseField>

<ResponseField name="elapsed_ms" type="number">
  Server-side processing time in milliseconds
</ResponseField>

```json
{
  "created": 2,
  "ids": ["01J9Z3K4M5N6P7Q8R9S0T1V2W3", "01J9Z3K4M5N6P7Q8R9S0T1V2W4"],
  "elapsed_ms": 84.2
}
```
