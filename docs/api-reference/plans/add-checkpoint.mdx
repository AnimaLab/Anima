## POST /api/v1/plans/{id}/checkpoints

A checkpoint is a milestone of a plan whose progress is tracked on its own. A new checkpoint starts with status `pending`, and its creation is written to the audit log.

<ParamField header="X-Anima-Namespace" type="string" required>
  Namespace of the plan
</ParamField>

<ParamField path="id" type="string" required>
  Plan ID. The plan must belong to the namespace itself (child namespaces excluded); another plan ID gives `500` with `plan <id> does not exist in namespace <namespace>`.
</ParamField>

## Request Body

<ParamField body="checkpoint_key" type="string" required>
  Short stable key for the checkpoint, e.g. `backup-done`. Empty key gives `400`.
</ParamField>

<ParamField body="title" type="string" required>
  Human-readable title. Empty title gives `400`.
</ParamField>

<ParamField body="order_index" type="integer" default="0">
  Position of the checkpoint in the plan; negative values become `0`
</ParamField>

<ParamField body="expected_by" type="string">
  When the checkpoint is expected to be reached, stored as given
</ParamField>

<ParamField body="metadata" type="object">
  Arbitrary metadata. Values under sensitive keys (`password`, `secret`, `token`, `auth`, ...) are stored as `"[redacted]"`.
</ParamField>

## Response

Returns the created checkpoint.

<ResponseField name="id" type="string">
  Checkpoint ID
</ResponseField>

<ResponseField name="namespace" type="string">
  Namespace of the checkpoint
</ResponseField>

<ResponseField name="plan_id" type="string">
  Plan ID
</ResponseField>

<ResponseField name="checkpoint_key" type="string">
  Checkpoint key, trimmed
</ResponseField>

<ResponseField name="title" type="string">
  Title, trimmed
</ResponseField>

<ResponseField name="order_index" type="integer">
  Position in the plan
</ResponseField>

<ResponseField name="status" type="string">
  `pending`, `in_progress`, `completed`, `failed` or `skipped`
</ResponseField>

<ResponseField name="expected_by" type="string | null">
  Expected date
</ResponseField>

<ResponseField name="completed_at" type="string | null">
  When the checkpoint reached `completed` or `failed`
</ResponseField>

<ResponseField name="evidence" type="string | null">
  Evidence recorded with the latest status update
</ResponseField>

<ResponseField name="metadata" type="object | null">
  Checkpoint metadata
</ResponseField>

<ResponseField name="created_at" type="string">
  Creation time
</ResponseField>

<ResponseField name="updated_at" type="string">
  Last update time
</ResponseField>

## Example

```bash
curl -X POST http://localhost:3000/api/v1/plans/01JCP4Q8R2S3T4V5W6X7Y8Z9A0/checkpoints \
  -H "Content-Type: application/json" \
  -H "X-Anima-Namespace: default" \
  -d '{
    "checkpoint_key": "backup-done",
    "title": "Take a full backup of staging",
    "order_index": 1,
    "expected_by": "2026-11-20T12:00:00+00:00"
  }'
```
