## POST /api/v1/plans

A plan records a goal an agent is working toward, so its checkpoints, recovery branches, bound procedures and final outcome can be tracked across sessions. A new plan starts with status `active`, and its creation is written to the audit log.

<ParamField header="X-Anima-Namespace" type="string" required>
  Target namespace
</ParamField>

## Request Body

<ParamField body="goal" type="string" required>
  What the plan aims to achieve. Empty goal gives `400`.
</ParamField>

<ParamField body="priority" type="integer" default="5">
  Priority from 1 to 10; values outside the range are clamped
</ParamField>

<ParamField body="due_at" type="string">
  Due date, stored as given (an RFC 3339 timestamp is the natural choice)
</ParamField>

<ParamField body="metadata" type="object">
  Arbitrary metadata. Values under sensitive keys (names containing `password`, `secret`, `token`, `api_key`, `auth`, `session`, `cookie`, `ssn`, `credit_card`, ...) are stored as `"[redacted]"`, at any depth.
</ParamField>

## Response

Returns the created plan.

<ResponseField name="id" type="string">
  Plan ID
</ResponseField>

<ResponseField name="namespace" type="string">
  Namespace of the plan
</ResponseField>

<ResponseField name="goal" type="string">
  Goal, trimmed
</ResponseField>

<ResponseField name="status" type="string">
  `active`, `completed`, `failed` or `abandoned`
</ResponseField>

<ResponseField name="priority" type="integer">
  Priority (1-10)
</ResponseField>

<ResponseField name="due_at" type="string | null">
  Due date
</ResponseField>

<ResponseField name="metadata" type="object | null">
  Plan metadata
</ResponseField>

<ResponseField name="outcome" type="string | null">
  Outcome text, set by [Set Plan Outcome](/api-reference/plans/outcome)
</ResponseField>

<ResponseField name="outcome_confidence" type="number | null">
  Confidence in the outcome (0-1)
</ResponseField>

<ResponseField name="finished_at" type="string | null">
  When the plan reached `completed`, `failed` or `abandoned`
</ResponseField>

<ResponseField name="created_at" type="string">
  Creation time
</ResponseField>

<ResponseField name="updated_at" type="string">
  Last update time
</ResponseField>

## Example

```bash
curl -X POST http://localhost:3000/api/v1/plans \
  -H "Content-Type: application/json" \
  -H "X-Anima-Namespace: default" \
  -d '{
    "goal": "Migrate the staging database to Postgres 17",
    "priority": 7,
    "due_at": "2026-11-30T17:00:00+00:00",
    "metadata": {"ticket": "OPS-412"}
  }'
```
