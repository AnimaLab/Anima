## GET /api/v1/plans/{id}/checkpoints

Lists the checkpoints of a plan in plan order, to see how far it has progressed.

<ParamField header="X-Anima-Namespace" type="string" required>
  Target namespace (its child namespaces are included)
</ParamField>

<ParamField path="id" type="string" required>
  Plan ID
</ParamField>

## Response

Returns an array of checkpoints ordered by `order_index`, then `created_at`, both ascending. An unknown plan ID returns an empty array. Each checkpoint has the fields described in [Add Checkpoint](/api-reference/plans/add-checkpoint).

<ResponseField name="id" type="string">
  Checkpoint ID
</ResponseField>

<ResponseField name="namespace" type="string">
  Namespace of the checkpoint
</ResponseField>

<ResponseField name="plan_id" type="string">
  Plan ID
</ResponseField>

<ResponseField name="checkpoint_key" type="string">
  Checkpoint key
</ResponseField>

<ResponseField name="title" type="string">
  Title
</ResponseField>

<ResponseField name="order_index" type="integer">
  Position in the plan
</ResponseField>

<ResponseField name="status" type="string">
  `pending`, `in_progress`, `completed`, `failed` or `skipped`
</ResponseField>

<ResponseField name="expected_by" type="string | null">
  Expected date
</ResponseField>

<ResponseField name="completed_at" type="string | null">
  When the checkpoint reached `completed` or `failed`
</ResponseField>

<ResponseField name="evidence" type="string | null">
  Evidence recorded with the latest status update
</ResponseField>

<ResponseField name="metadata" type="object | null">
  Checkpoint metadata
</ResponseField>

<ResponseField name="created_at" type="string">
  Creation time
</ResponseField>

<ResponseField name="updated_at" type="string">
  Last update time
</ResponseField>

## Example

```bash
curl http://localhost:3000/api/v1/plans/01JCP4Q8R2S3T4V5W6X7Y8Z9A0/checkpoints \
  -H "X-Anima-Namespace: default"
```
