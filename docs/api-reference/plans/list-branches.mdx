## GET /api/v1/plans/{id}/branches

Lists the recovery branches opened on a plan, newest first.

<ParamField header="X-Anima-Namespace" type="string" required>
  Target namespace (its child namespaces are included)
</ParamField>

<ParamField path="id" type="string" required>
  Plan ID
</ParamField>

## Response

Returns an array of branches ordered by `created_at` descending. An unknown plan ID returns an empty array. Each branch has the fields described in [Add Recovery Branch](/api-reference/plans/add-branch).

<ResponseField name="id" type="string">
  Branch ID
</ResponseField>

<ResponseField name="namespace" type="string">
  Namespace of the branch
</ResponseField>

<ResponseField name="plan_id" type="string">
  Plan ID
</ResponseField>

<ResponseField name="source_checkpoint_id" type="string | null">
  Checkpoint the branch starts from
</ResponseField>

<ResponseField name="branch_label" type="string">
  Branch label
</ResponseField>

<ResponseField name="trigger_reason" type="string">
  Why the branch was opened
</ResponseField>

<ResponseField name="status" type="string">
  `active`, `resolved` or `abandoned`
</ResponseField>

<ResponseField name="branch_plan" type="any | null">
  Alternative steps
</ResponseField>

<ResponseField name="metadata" type="object | null">
  Branch metadata
</ResponseField>

<ResponseField name="resolution_notes" type="string | null">
  Notes recorded when the branch was resolved
</ResponseField>

<ResponseField name="created_at" type="string">
  Creation time
</ResponseField>

<ResponseField name="updated_at" type="string">
  Last update time
</ResponseField>

<ResponseField name="resolved_at" type="string | null">
  When the branch reached `resolved` or `abandoned`
</ResponseField>

curl http://localhost:3000/api/v1/plans/01JCP4Q8R2S3T4V5W6X7Y8Z9A0/branches \
  -H "X-Anima-Namespace: default"
