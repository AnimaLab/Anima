## GET /api/v1/skills/{name}

Returns a skill with its full content, for a model that decided the skill applies to its task. See [Briefing and skills](/concepts/briefing-and-skills).

<ParamField header="X-Anima-Namespace" type="string" required>
  Target namespace
</ParamField>

<ParamField path="name" type="string" required>
  Skill name: lowercase letters, digits and hyphens, at most 64 characters, neither starting nor ending with a hyphen. Any other name gives `400`; an unknown name gives `404`.
</ParamField>

## Response

`anima` returns the stored skill of that name when there is one, the built-in skill otherwise.

<ResponseField name="id" type="string">
  Skill ID (`builtin-anima` for the built-in skill)
</ResponseField>

<ResponseField name="namespace" type="string">
  Namespace of the skill
</ResponseField>

<ResponseField name="name" type="string">
  Skill name
</ResponseField>

<ResponseField name="description" type="string">
  When to use the skill
</ResponseField>

<ResponseField name="content" type="string">
  The instructions
</ResponseField>

<ResponseField name="version" type="integer">
  Starts at 1, goes up when the description or content changes
</ResponseField>

<ResponseField name="created_at" type="string">
  Creation time (RFC 3339); empty for the built-in skill
</ResponseField>

<ResponseField name="updated_at" type="string">
  Last change (RFC 3339); empty for the built-in skill
</ResponseField>

<ResponseField name="builtin" type="boolean">
  `true` for the built-in `anima` skill
</ResponseField>

## Example

```bash
curl http://localhost:3000/api/v1/skills/release-checklist \
  -H "X-Anima-Namespace: default"
```
