## PUT /api/v1/skills/{name}

Stores a skill under a name, creating it or replacing its description and content. See [Briefing and skills](/concepts/briefing-and-skills).

<ParamField header="X-Anima-Namespace" type="string" required>
  Target namespace
</ParamField>

<ParamField path="name" type="string" required>
  Skill name: lowercase letters, digits and hyphens, at most 64 characters, neither starting nor ending with a hyphen. Any other name gives `400`. Saving `anima` replaces the built-in skill in this namespace.
</ParamField>

## Request Body

<ParamField body="description" type="string" required>
  One or two sentences saying when to use the skill; this is what the briefing shows. Runs of whitespace are collapsed to single spaces. Empty gives `400`.
</ParamField>

<ParamField body="content" type="string" required>
  The instructions. Trailing whitespace is trimmed. Empty or blank gives `400`.
</ParamField>

## Response

The saved skill, same shape as [Get Skill](/api-reference/skills/get). A new skill starts at version 1. An update raises the version and `updated_at` only when the description or content changes; saving identical values returns the skill unchanged.

<ResponseField name="id" type="string">
  Skill ID
</ResponseField>

<ResponseField name="namespace" type="string">
  Namespace of the skill
</ResponseField>

<ResponseField name="name" type="string">
  Skill name
</ResponseField>

<ResponseField name="description" type="string">
  Description as stored
</ResponseField>

<ResponseField name="content" type="string">
  Content as stored
</ResponseField>

<ResponseField name="version" type="integer">
  Current version
</ResponseField>

<ResponseField name="created_at" type="string">
  Creation time (RFC 3339)
</ResponseField>

<ResponseField name="updated_at" type="string">
  Last change (RFC 3339)
</ResponseField>

<ResponseField name="builtin" type="boolean">
  Always `false`
</ResponseField>

## Example

```bash
curl -X PUT http://localhost:3000/api/v1/skills/release-checklist \
  -H "Content-Type: application/json" \
  -H "X-Anima-Namespace: default" \
  -d '{
    "description": "Steps to cut a release of a Rust service. Use when the user asks to release, tag or publish a version.",
    "content": "# Release checklist\n\n1. Bump the version in Cargo.toml.\n2. Run the full test suite.\n3. Tag the commit and push the tag."
  }'
```
