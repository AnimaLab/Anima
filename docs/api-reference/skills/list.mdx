## GET /api/v1/skills

Lists the skills stored in the namespace, so a caller can pick one to load with [Get Skill](/api-reference/skills/get). See [Briefing and skills](/concepts/briefing-and-skills).

<ParamField header="X-Anima-Namespace" type="string" required>
  Target namespace. Skills belong to exactly this namespace.
</ParamField>

## Response

<ResponseField name="skills" type="object[]">
  Stored skills, most recently updated first, followed by the built-in `anima` skill unless a stored skill named `anima` replaces it.

  <Expandable title="skill">
    <ResponseField name="name" type="string">
      Skill name
    </ResponseField>
    <ResponseField name="description" type="string">
      When to use the skill
    </ResponseField>
    <ResponseField name="version" type="integer">
      Starts at 1, goes up when the description or content changes
    </ResponseField>
    <ResponseField name="updated_at" type="string">
      Last change (RFC 3339); empty for the built-in skill
    </ResponseField>
    <ResponseField name="size" type="integer">
      Length of the content in characters, the cost of loading it
    </ResponseField>
    <ResponseField name="builtin" type="boolean">
      `true` for the built-in `anima` skill shipped with the server
    </ResponseField>
  </Expandable>
</ResponseField>

## Example

```bash
curl http://localhost:3000/api/v1/skills \
  -H "X-Anima-Namespace: default"
```
