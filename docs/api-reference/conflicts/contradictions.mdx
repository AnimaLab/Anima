## GET /api/v1/contradictions

Returns contradiction ledger entries — records of when one memory superseded another via correction or reconsolidation.

<ParamField header="X-Anima-Namespace" type="string" required>
  Target namespace
</ParamField>

<ParamField query="limit" type="integer" default="50">
  Maximum entries to return (1-500)
</ParamField>

<ParamField query="offset" type="integer" default="0">
  Pagination offset
</ParamField>

## Response

Array of contradiction entries, newest first. Entries from child namespaces (`<namespace>/...`) are included. Each entry:

- `id` — unique entry ID
- `namespace` — namespace the entry was recorded in
- `old_memory_id` — the superseded memory
- `new_memory_id` — the superseding memory
- `resolution` — how the conflict was resolved (`user_correction_supersede`, `reconsolidation_supersede`)
- `provenance` — JSON context recorded with the resolution (e.g. `source`, `reason`), or `null`
- `created_at` — when the resolution happened
- `old_content` — content of the old memory, present while it is still in the database
- `new_content` — content of the new memory, present while it is still in the database

## Example

```bash
curl http://localhost:3000/api/v1/contradictions?limit=10 \
  -H "X-Anima-Namespace: default"
```
