---
title: 'List State Transitions'
description: 'List the state transitions between memories'
---

## GET /api/v1/transitions

Lists the directed state transitions recorded between memories, strongest first.

<ParamField header="X-Anima-Namespace" type="string" required>
  Target namespace (its child namespaces are included)
</ParamField>

## Query Parameters

<ParamField query="limit" type="integer" default="100">
  Maximum number of transitions to return (1-500)
</ParamField>

## Response

Returns an array of transitions ordered by `confidence` descending, then `updated_at` descending.

<ResponseField name="id" type="string">
  Transition ID
</ResponseField>

<ResponseField name="namespace" type="string">
  Namespace of the transition
</ResponseField>

<ResponseField name="from_memory_id" type="string">
  Source memory ID
</ResponseField>

<ResponseField name="to_memory_id" type="string">
  Target memory ID
</ResponseField>

<ResponseField name="transition_type" type="string">
  `temporal`, `state_change`, `dependency` or `supersession`
</ResponseField>

<ResponseField name="confidence" type="number">
  Confidence (0-1)
</ResponseField>

<ResponseField name="evidence" type="string | null">
  What supports the transition
</ResponseField>

<ResponseField name="created_at" type="string">
  When the transition was first recorded
</ResponseField>

<ResponseField name="updated_at" type="string">
  Last update time
</ResponseField>

## Example

```bash
curl "http://localhost:3000/api/v1/transitions?limit=50" \
  -H "X-Anima-Namespace: default"
```
