---
title: 'Health Check'
description: 'Check if the server is running'
---

## GET /health

Liveness probe: returns `200` while the process is up. It works without the `X-Anima-Namespace` header.

## Response

```json
{
  "status": "ok",
  "service": "anima",
  "version": "0.3.0"
}
```

## GET /health/ready

Deep readiness check that pings the database, runs a test embedding, and reports the background processor. Use this for orchestration and load-balancer health probes.

### Response

`checks` is always present. `db` and `embedder` are `"ok"` or `{"error": "..."}`. `processor` is `"disabled"` when the processor is off, or its live state:

```json
{
  "status": "ready",
  "service": "anima",
  "version": "0.3.0",
  "checks": {
    "db": "ok",
    "embedder": "ok",
    "processor": {
      "status": "running",
      "queue_depth": 0,
      "in_flight": 1
    }
  }
}
```

Returns `503` with `"status": "degraded"` when the database or the embedder check fails:

```json
{
  "status": "degraded",
  "service": "anima",
  "version": "0.3.0",
  "checks": {
    "db": "ok",
    "embedder": { "error": "model not loaded" },
    "processor": "disabled"
  }
}
```
