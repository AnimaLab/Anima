## GET /api/v1/calibration/weights

Returns the current hybrid search weights (`weight_vector` and `weight_keyword`). These may differ from the config values if the auto-tuner has adjusted them based on calibration observations.

## Response

```json
{
  "weight_vector": 0.62,
  "weight_keyword": 0.38
}
```

The weights are server-wide, shared by all namespaces. The auto-tuner runs every 300 seconds (`ANIMA_CALIBRATION_RECOMPUTE_SECS`) over the latest 5,000 retrieval observations, once at least 50 are available, and weights each source (vector vs keyword) by how much of its score went to positive retrieval outcomes. Each weight is floored at 0.1 before the pair is normalised to sum to 1. New weights are applied when either one moves by more than 0.05.

## Example

```bash
curl http://localhost:3000/api/v1/calibration/weights
```
