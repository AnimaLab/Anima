## POST /api/v1/conversations

Creates an empty conversation in which a chat client saves its messages.

<ParamField header="X-Anima-Namespace" type="string" required>
  Namespace the conversation belongs to
</ParamField>

## Request Body

<ParamField body="title" type="string" default="New Chat">
  Conversation title
</ParamField>

<ParamField body="mode" type="string" default="rag">
  Chat mode to record, e.g. `rag` or `tool` (see [Chat](/api-reference/chat/chat)). Stored as given.
</ParamField>

## Response

<ResponseField name="id" type="string">
  Conversation ID
</ResponseField>

<ResponseField name="namespace" type="string">
  Namespace of the conversation
</ResponseField>

<ResponseField name="title" type="string">
  Conversation title
</ResponseField>

<ResponseField name="mode" type="string">
  Chat mode
</ResponseField>

<ResponseField name="messages" type="string">
  The messages as a JSON-encoded array in a string, `"[]"` for a new conversation
</ResponseField>

<ResponseField name="created_at" type="string">
  Creation time (RFC 3339)
</ResponseField>

<ResponseField name="updated_at" type="string">
  Last change (RFC 3339)
</ResponseField>

## Example

```bash
curl -X POST http://localhost:3000/api/v1/conversations \
  -H "Content-Type: application/json" \
  -H "X-Anima-Namespace: default" \
  -d '{"mode": "tool"}'
```

```json
{
```
