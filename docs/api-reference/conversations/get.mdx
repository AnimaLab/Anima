## GET /api/v1/conversations/{id}

Returns a conversation with its saved messages. The endpoint takes no namespace header; the conversation is found by ID alone.

<ParamField path="id" type="string" required>
  Conversation ID. An unknown ID gives `404`.
</ParamField>

## Response

<ResponseField name="id" type="string">
  Conversation ID
</ResponseField>

<ResponseField name="namespace" type="string">
  Namespace of the conversation
</ResponseField>

<ResponseField name="title" type="string">
  Conversation title
</ResponseField>

<ResponseField name="mode" type="string">
  Chat mode
</ResponseField>

<ResponseField name="messages" type="string">
  The messages as a JSON-encoded array in a string, exactly as last saved with [Update Conversation](/api-reference/conversations/update)
</ResponseField>

<ResponseField name="created_at" type="string">
  Creation time (RFC 3339)
</ResponseField>

<ResponseField name="updated_at" type="string">
  Last change (RFC 3339)
</ResponseField>

## Example

```bash
curl http://localhost:3000/api/v1/conversations/01J9Z7E5F6G7H8J9K0M1N2P3Q4
```

