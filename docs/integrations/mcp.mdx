The MCP server wraps Anima as a set of tools that any MCP-compatible assistant can call. Available tools include `memory_search`, `memory_add`, `memory_update`, `memory_delete`, `memory_stats`, `memory_ask`, and `memory_reflect`.

<Note>
The server binary has the same tools built in: `anima-server mcp`. Use
[`anima-server connect`](/integrations/connect) to set it up; the TypeScript
bridge below is for clients that do not have the binary.
</Note>

## Setup

```bash
cd mcp
npm install
npm run build
```

## Configuration

Point your MCP client (Claude Desktop, Cursor, etc.) at the built MCP server. The MCP bridge connects to the Anima REST API, which must be running.

The bridge expects the Anima API at `http://localhost:3000` by default. Set `ANIMA_BASE_URL` to change it, and `ANIMA_API_KEY` if the server requires an API key.

## Available Tools

| Tool | Description |
|------|-------------|
| `memory_search` | Hybrid search over stored memories. Results include `category`, `confidence`, and `source`. |
| `memory_add` | Store a new memory (accepts optional `category` parameter) |
| `memory_update` | Update an existing memory |
| `memory_delete` | Delete a memory |
| `memory_stats` | Get memory store statistics |
| `memory_ask` | Ask a question with enriched retrieval |
| `memory_reflect` | Trigger reflection on recent memories |
| `memory_list` | List stored memories |
| `memory_discover` | Find memories similar to example memories, with optional negative examples |
| `memory_briefing` | Short session briefing: profile, project memories and the skill index |
| `skill_list` | List stored skills |
| `skill_get` | Load a skill's instructions |
| `skill_save` | Create or update a skill |
| `skill_delete` | Delete a skill |
